# ZX Audio downloads

Installers and other public files for ZX Audio plugins. Get them from the [Releases](../../releases) page.

Product information, manuals and support are at https://zxaudio.ca. Each release has one installer named like `PHASE-ZERO-<version>-win64.exe`, and its SHA-256 checksum is in the release notes. A license key is needed to activate the plugin. This repo may also host factory preset packs later.
